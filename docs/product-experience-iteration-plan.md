## 3. 本轮交付：Agent 面试决策闭环（首批已验证，待人审）

**用户目标**：把“如何面试”交给结合岗位、材料和现场回答作判断的 Agent；能主动查资料/前文、诊断回答、调整考点与角色，决定追问、澄清、换题或结束。实现仍用 Java/Spring + 手写 ReAct，不引框架；Java 守住租户、计费、状态和硬预算。

**内部模型与兼容**：State 保存 JD/所选简历快照、计划及lastDecision（含END证据）；Decision保存动作、实际角色、目的、简短依据、有限证据与调用/token/耗时统计，不存推理链。V5增session.agent_state / turn.agent_metadata LONGTEXT，旧NULL场继续legacy。新场开关默认true；角色从已启用集合选，追问/澄清继承当前角色，最多两层；maxQuestions是上限，Agent可提前END。HTTP字段和SSE事件不增加；工具不接受用户/会话ID。具体预算和证据范围见 [方案](agent-decision-runtime.md)。

**配套评价**：技术维度=正确性/完整性/深度/实证；行为维度=STAR结构/行动细节/结果与反思/表达与抗压。评分严格校验四维整数0–2、合计0–8及权威赛道，异常不补0；Critic 得到已存证据，过滤伪造/重复轮次并恢复真实题目/评分/赛道。资料声明不自动变成已核实事实，未知经历或数字用占位符。评分校验随主线交付，不独立取代 Agent 重构。

**验收**：

1. 原生 tool_calls 的接收、参数校验、分发、结果回填与再决策闭环；无检索需求可直接决定，不强制空转。非法工具、越权、重复ID及模型/工具/token/时间预算均有离线用例。
2. 低分直接换题、高分核实依据、明确不会停止、矛盾查前文、按目的换角色；两层/主问题上限/重复题/启用角色守卫。语义去重、岗位适配和必考覆盖效果仍需真实内容评测。
3. 本人 JD/所选简历快照、排除其他简历版本，项目等材料取证时留有限片段；State/实际角色/证据经持久化仍可恢复。旧套件关闭新场开关，新 Agent 套件启用，兼容旧 NULL 数据。
4. 两赛道合法0/8/中间分和code fence通过；缺维/null/错误维名/额外维度、字符串/小数/布尔、维度-1/3、总分越界/合计不等拒绝；空正文/非法JSON保持失败语义。评分失败保留回答、null分且不写错题；报告权威字段不被模型覆盖。
5. Agent出题非业务失败后同文恢复，不重复判分；UI“继续生成下一步”复用原答并提示新调用积分。answer对402/409业务异常不回滚已保存回答评分；不同内容不能覆盖旧答。answer/end同场guard及hint=0行锁保护，竞争者不发第二次评分；多实例/MySQL NOWAIT未实测。恢复模型/embedding新调用仍收费。
6. 最终 `.\mvnw.cmd test`：310项、0failure/error、8skip（6个MySQL、旧量化opt-in、新AgentLiveSmokeTest）；package成功。Chrome fixture17组、360/390px八页通过；真实jar首页200、注册/鉴权额度通过（H2，Redis未起，不等于生产就绪）。日志 `target/agent-final-test.log`、`agent-package.log`、`agent-browser-test.log`、`agent-startup.log`。同一合成案例真实DeepSeek跑两次，首轮发现预设语气后加强约束再复测，合计9次对话/19283 token；不是独立案例评测或质量非劣效证据，仍需扩大人工评阅。

**未完成边界**：非所选简历的全部资料并未开场冻结；计划仍为有限文本状态，未做到独立岗位能力图谱和必考覆盖证明；没有全场真实模型质量/成本新基线。长事务、多实例与MySQL锁语义实测、跨重试的完整持久幂等、真正异步、正文流式、报告失败单独重试仍待专项。UI已支持出题失败恢复，fixture验证不替代真实模型质量；prod先备份再迁移V5，迁移兼容本地已建列。不自动提交/部署。

## 5. 统一实施与验证边界

- 新 Agent 场得到 JD/所选简历快照，后续决策/判分/Critic 获有限前文和已保存证据；旧场仍是原首题RAG/留痕语义。answer/end模型调用仍在事务内，SSE仍在编排返回后投递；不能宣称异步或真流式已完成。
- 内部有界执行循环已纳本轮；短事务、持久任务/请求幂等、报告失败恢复和模型流式另行设计。保留同步首题/end完整报告及402/409结算边界，不引 MQ/WebFlux/Agent框架。
- 分段记录 API/检索/embedding/判分/出题/Critic/重试/token；内部细节进 DB 或结构化日志，页面只给真实状态；JWT/Key/私密全文不入日志。断线不等于取消，重放不重复生成。
- 当前没有稳定全场性能门槛。此前本地反馈 100ms、异步受理 P95<1s、正文<3s、一轮<15s、报告<45s 均只是候选体验目标；按输入量/场长/厂商建立全链路成功与失败基线后再锁阈值。
- 代码批次全量 mvnw 回归，UI 发布加 `scripts/frontend-smoke.cjs`；涉及租户/计费/持久化补真实依赖验证。真实模型质量评阅与确定性测试分开，保留原始样本，不只挑通过输出。
- 不自动 commit/push/合并/部署；迁移先备份。完成状态只写有证据的范围。历史提案与阶段测试见 [迭代摘要](archive/iteration-history.md)，完整验收见专项清单。
