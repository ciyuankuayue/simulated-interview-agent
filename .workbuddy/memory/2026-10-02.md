## 教用户测试验收方法论
- 用户诉求：完全不会测试、不愿盲信 AI，要求"具体到点击哪、什么命令、怎么判断"的详细教学。
- 核心 reframe：**验收 ≠ 写测试**——用户只需做三件事：跑别人写好的测试 + 启动 app 点一遍 + 读改动范围，不需会写 Java 测试代码。

- 强调不能盲信 AI 的具体失效模式：漏跑测试、假绿(Skipped)、只验后端不点浏览器、夹带无关改动。
- 用户情绪基线：焦虑"不会测试"，reframe 后降低门槛有效。

## 架构决策咨询：是否加 Vue（用户问，给出"不加"结论）
- 用户疑问：基于 task 最终效果 + 服务器上线需求，是否改用 Vue？
